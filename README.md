# 🚀 Estudos de Git & Versionamento

Este repositório foi criado com o objetivo de **aprender e praticar Git e GitHub**, desde os conceitos básicos até fluxos mais avançados, aplicando o versionamento em projetos reais de programação.

---

## 📚 Sobre o Curso / Estudos

Durante meus estudos, estou aprendendo:

- Conceitos fundamentais de **controle de versão**
- Uso do **Git no dia a dia de desenvolvimento**
- Boas práticas de commits e organização de repositórios
- Integração entre **Git + GitHub**
- Aplicação do Git em projetos de programação (Java, C, Python, etc.)

Este repositório funciona como um **diário de aprendizado**, onde cada commit representa uma evolução no conhecimento.

---

## 🛠️ Ferramentas Utilizadas

- **Git**
- **GitHub**
- **Markdown**


---

## 🧠 Conteúdos Praticados

- Inicialização de repositórios (`git init`)
- Commits e histórico (`git add`, `git commit`, `git log`)
- Branches e merges
- Repositórios remotos (`git push`, `git pull`)
- Resolução de conflitos
- Organização de projetos com `.gitignore`
- Documentação com `README.md`

---

## 🗺️ Roadmap de Aprendizado

 Conceitos básicos de Git
 Commits e versionament
 GitHub e repositórios remotos
 Branches avançadas
 Rebase e Cherry-pick
 Git aplicado a projetos maiores

---

## 🎯 Objetivo

Consolidar o uso do **Git como ferramenta essencial no desenvolvimento de software**, criando uma base sólida para projetos acadêmicos e profissionais.
